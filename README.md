A sleek, modern calculator web application with a dark theme and smooth animations built with vanilla JavaScript and Vite.

## Features

- Modern dark-themed UI with gradient effects
- Responsive design that works on all devices
- Smooth hover animations and transitions
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Decimal number support
- Error handling for invalid calculations
- Clean and intuitive interface

## Prerequisites

- Node.js 14+ and npm (for Vite)
- Modern web browser

## Installation

```bash
git clone https://github.com/Benjy0812/ModernDarkCalculator.git
cd ModernDarkCalculator
npm install
```

## Usage

**Development server:**
```bash
npm run dev
```

**Build for production:**
```bash
npm run build
```

**Preview production build:**
```bash
npm run preview
```

**Or simply open `index.html` in your browser for basic usage without Vite.**

## Project Structure

```
ModernDarkCalculator/
├── index.html          # Main HTML file
├── styles.css          # Stylesheet with dark theme
├── script.js           # Calculator logic
├── package.json        # Vite configuration
└── README.md           # Documentation
```

## How It Works

The calculator uses a simple grid layout with buttons for digits (0-9), operators (+, -, *, /), decimal point, equals, and clear functions. Click buttons to build your calculation, then press `=` to see the result.

## Technologies Used

- **HTML5** - Structure
- **CSS3** - Styling with gradients and animations
- **JavaScript** - Calculator logic and interactivity
- **Vite** - Build tool and development server
